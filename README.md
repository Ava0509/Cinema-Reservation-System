# Cinema Reservation System

Python + SQL project

**Current Features**
* Customer registration and login
* SHA-256 hashed passkey authentication
* Movie listings and movie details
* Show date, time and screen display
* Interactive seat-selection interface
* 120-seat layout for each screen
* Seat availability tracking
* Customer booking and booking confirmation
* Booking search and retrieval
* Booking cancellation
* Automatic booking status and seat availability updates
* Database-driven storage using MySQL
* Graphical user interface using Tkinter
* Error handling and input validation
* Transaction handling with database commit/rollback

**Modules Used**
* Tkinter
* mysql.connector
* hashlib
* Custom modules - database.py & Seat_selection.py
